# Switch × Skills 实机验收方案与费用边界

状态：**待授权，未执行计费请求**。范围必须逐客户端、系统、架构、
Skills 执行器 SHA、Switch／客户端版本和会话模式记录，不以一次 Web 生成覆盖所有格。

## 第一阶段：不产生专用模型计费

1. 使用测试账户和两类明确分组（聊天＋含目标模型；聊天＋不含目标模型）。
   由用户在 Switch 选择并应用，验收器只记录脱敏成功／失败和版本，
   不读取、导出或索取 Key。配置应用、Key 刷新若需自动操作也先纳入授权。
2. 首个重点客户端为 VS Code 本地默认 profile，另选已配置的 OpenCode 或 DSH
   作对照。安装候选 Skills 后新开对话，确认实际加载路径和版本及本地执行能力。
   启动 Agent 可能消耗聊天 token，须纳入实机总预算，不能称整个阶段绝对免费。
3. 由对应宿主执行器做用户明确要求的模型发现，记录所需精确 IDs 是否可见。
   查看 Switch 的脱敏分组名单并与所选 Key 关联结果核对。此步只验③目录投影，
   不验④专用 API。不要运行所有客户端探测或复制一个客户端的 Key。
4. 多分组改变名单后重新应用，确认增加／移除都生效；不同 Key、
   被拒绝 Key、便携／命名／远程 profile、会话覆盖单独记录。
   不修改生产 Key 来制造故障；优先使用合成离线测试，真实拒绝用专用测试 Key。
   若服务端错误放行拒绝测试，仍可能计费，因此真实拒绝 POST 也需授权。

## 第二阶段：首个宿主的有限专用请求

先完成①②③，再逐项提交，不批量启动。每行最多一次 POST，不因超时／
交付失败重提；已有 ID 只查原任务。只有获得新授权才能重新提交。

| 用例 | 精确模型候选与输入 | 最多提交 | 通过条件 |
| --- | --- | --- | --- |
| 图片生成 | `gpt-image-2`，1K、1张、1:1、简单非私人图案 | 1 | 原任务完成，实际客户端打开图片／附件 |
| 图片编辑 | 同模型，使用上一行原图本地字节，小幅颜色修改 | 1 | multipart edit 一次；修改结果实际可打开 |
| 图生视频 | `grok-imagine-video-1.5`，480p、5秒、同图作首帧；以实时参数合同为准 | 1 | 返回原 ID，原生视频可播放，参考图未被改写为纯文本 |
| 配音 | `stepaudio-2.5-tts`，不超过30字，已审 voice | 1 | 专用接口返回有效音频，客户端能播放／附件交付 |
| 转写 | `stepaudio-2.5-asr`，上一行音频作为当前附件 | 1 | multipart 原字节、最终转写文本实际展示 |
| 声音场景 | `stepaudio-3-gen-preview`，一句短场景 | 1 | 有效音频，实际播放／交付 |
| 音乐 | `stepaudio-3-music-preview`，短器乐描述 | 1 | 网关音乐补丁已部署；原 ID 续接，MP3/WAV实际播放 |
| Jev | `jev-latest`，一段短文本，同请求 Choice/Score/Noul | 1 | 原始选项、数值、概率／legend 正确展示，不冒充聊天回答 |

合计上限 **8 次专用提交／首个宿主**。缺少实时分组权限、价格或路由的行先跳过，
不换模型。第一个客户端成功后，再逐客户端授权最小必要用例；
跨客户端读取旧任务仅在确认同一合法账号／原 Key 绑定并获授权时使用，
不能借此绕过该客户端专用 POST 验收。

这些公开值未确认账户分组倍率、计费模式／表达式及最终报价的适用顺序，
**不是测试总价或扣费上限**。不得取最低公开数字直接申请付费授权。
执行前需取得所选分组的权威报价（币种、单价／表达式、参数、有效时间），
计算两次图片＋一次视频＋各音频／Jev上界，并单列聊天 token 预算。
报价未知的行暂停，不能称免费；只批准固定预算但无法估计单次上界时也不执行。

建议先授权只读验收和取得上述报价，再以具体金额批准首批图片／编辑／视频，
音频、音乐、Jev在路由与报价齐全后另行批准。报告只保留脱敏模型 ID、
状态码、次数、阶段耗时、可见／不可见、实际费用及附件交付结果，
不保存 Key、请求正文、用户媒体或原始响应。
