# Pure Tokens Skill 使用须知

安装完成后，先确认当前宿主已经连接到 Pure Tokens；Skill 会使用当前宿主连接完成固定 API 请求，不需要用户粘贴 API Key。

常用示例：

- `生成一张日落时分的山间湖泊图片。`
- `使用 grok-imagine-image 生成一张产品插画。`
- `生成同一主题的 3 张图片变体。`
- `生成一段 5 秒、电影感的纸船漂过河面的短视频。`
- `用附件作为首帧生成视频。`（请明确是“首帧”还是“参考图”。）
- `查询当前可用的生图和生视频模型。`
- `查询当前 Pure Tokens 余额。`
- `更新 Pure Tokens Skills。`

注意：

- 模型、参数、尺寸、参考媒体和编辑能力以当前认证模型目录的明确声明为准；未声明的选项不会提交。
- 图片和视频任务是异步的。超时或结果不确定时不会自动重复创建任务；如果已有 task ID，可以明确要求继续查询同一任务。
- `200cm × 230cm` 等物理尺寸不能作为 API 像素尺寸精确保证，请改用模型声明的像素尺寸或比例。
- 本地附件只有在所选模型声明对应的 multipart 操作时才会发送；不会偷偷上传、转存或改成纯文生请求。
- 生成成功必须交付原生图片或视频字节；链接、HTML、SVG 或任务状态文字不算成功结果。
