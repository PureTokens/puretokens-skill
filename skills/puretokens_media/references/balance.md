# Balance rules

只处理当前 **Pure Tokens** 连接的余额查询。余额请求不进入图片或视频流程：不读取媒体目录、不选择模型、不调用五个媒体 MCP 工具，也不依据价格、历史用量、缓存或本地配置估算余额。

只有宿主明确向当前任务公开“当前 Pure Tokens 连接的、已认证、只读余额查询能力”时，才调用它一次。只报告该调用实际返回的快照字段；不得自行换算、补全币种、推测时间、构造余额 URL、请求头、请求体或响应格式。

若 CC Switch 没有把该能力开放给当前对话，直接告诉用户：当前 Pure Tokens 连接可在 CC Switch 的供应商卡查看余额，但这个宿主尚未把余额查询开放给对话执行。请打开当前 Pure Tokens 供应商卡的“用量查询”查看或测试余额。

这不是“不支持余额”，也不要求用户安装 Pure Tokens Desktop 或 MCP。宿主返回无效或安全错误时，只说明未取得可读取的实时余额，并给出同一入口；绝不显示 `0`、旧余额或估算值，也不自动重试、切换连接或改用第三方服务。
