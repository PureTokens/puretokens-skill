# 图片场景提示词指南

只在用户要求协助组织提示词、或生成需求缺少必要表达时读取对应场景。用户仅要提示词时只交付文字；已给定原样提示词时逐字传递，不润色、翻译、追加模板或追问已有答案。

## 通用原则

- 区分提示词与 API 参数。提示词里的“8K 质感”可保留，但不代表实际 8K 输出，不自动填进 size/image_size；用户明确要求实际分辨率时按 profile 校验，不暗中降级。
- 只整理用户已表达的主体、用途、构图、文案和限制；不凭空增加品牌、人物、故事、收费任务或效果保证。缺少可选细节不强制追问；角色、必需参数或互相冲突的要求才澄清。
- 明确每张附件是编辑原图、外观参考、风格参考还是组合素材。提示词说明角色不代替传输原始附件；字段、数量、组合由 profile 决定。
- 不默认追加“无文字”“无水印”等负面模板。模型未声明 negative_prompt 等字段时不得发送；用户已有的限制可保留在 prompt 中。

## 商品图

按“商品主体 → 必须保留 → 要改变的环境／构图”组织。例：用户要白底杯子主图时，保留杯形和标志，背景换为白色；不擅自添加促销字、品牌口号或新配件。用户未明确要求的保留项不要承诺逐像素一致。

## 带文字海报

逐字保留用户指定文字、标点与大小写，并明确是否只允许这些文案。用户说“只出现周末特调”时，不新增日期、店名、折扣或英文副标题。没有指定实际分辨率时使用已声明默认值，不把印刷尺寸直接传入 API。

## 局部编辑

分开写“只修改什么”和“其余保留什么”。例如只换背景，保留人物、衣服和构图。不得为表达“局部”虚构 mask 字段、生成蒙版、裁剪或重新编码原图；只有用户明确提供且 profile 声明的编辑输入才可发送。

## 参考图生成

保留用户对各图的角色说明，例如图 A 参考商品外观、图 B 参考配色。参考不等于承诺复制原图；无法确认输入角色或模型不支持该组合时，先说明缺口，不能把附件概括成文字后丢弃。
